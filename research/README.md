# Research track

Not part of the app. Notebooks, the old Streamlit dashboard and the label-based
evaluation scripts live here. The app (`backend/`, `engine/`, `frontend/`) does
not import anything from this folder.

`README.old.md` is the original experiment write-up. Its paths predate the
split: `src/` is now `engine/`, and `src/evaluation/` is now `research/evaluation/`.
